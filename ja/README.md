# はじめに

Mobile Security Framework（MobSF）は、モバイルアプリケーション（Android / iOS / Windows）のペネトレーションテスト、マルウェア解析、セキュリティ評価を自動化するオールインワンのフレームワークです。静的解析（Static Analysis）および動的解析（Dynamic Analysis）に対応しています。
